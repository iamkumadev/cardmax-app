CardMax · Design System

Every gift card is a voucher.
The UI is built like one.

A single component — the die-cut ticket stub — carries the idea that a gift card is something you tear off and redeem for cash. Everything below is the token set and component library that idea is built from.

01 · Color

Six roles, light and dark

Paper

--paper · page background

Surface

--surface · cards

Ink

--ink · primary text

Emerald

--emerald · primary action

Gold

--gold · reward, bonus

Coral

--coral · attention, errors

Usage rule: Emerald is the only color allowed on primary actions (buttons, active nav, links). Gold is reserved for reward/bonus moments — never a button. Coral is reserved for errors and destructive actions — never decorative. This restraint is what keeps the palette from feeling arbitrary.

02 · Typography

Three roles, one scale each

Fraunces — Display

Balance figures, hero type, section headers. Used sparingly — it's the "voice," not the workhorse.

04 · Card marks

Brand-neutral by design

Gift-card tiles never use real logos out of the box — this is a template, not a licensed asset pack. Instead each brand gets a monogram mark: an initial on a color drawn from the palette below, assigned deterministically by brand name. Replace with real artwork per-brand when you deploy for a specific store.

08 · Ticket component

The signature element

Every ticket has a body and a stub, separated by a dashed perforation with die-cut notches. The stub always holds the single most important action or status for that card — never decoration.
